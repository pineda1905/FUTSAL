## Guion de Pasos de Ejecución

1. Iniciar la Web API localmente en `http://localhost:5000` (o el puerto configurado).
2. Obtener un token JWT de administrador e insertarlo en la variable `@token` del archivo `api/1019_desempate_penales.http`.
3. Disponer de un `partidoId` real de un torneo activo con dos equipos participantes (Local y Visita).
4. **Paso A (Positivo):** Ejecutar la petición HTTP PUT `/api/Torneos/partidos/{{partidoId}}` enviando empate `golesLocal = 2`, `golesVisita = 2` y `ganadorId = {{equipoLocalId}}`.
5. Comprobar que la respuesta sea `200 OK` y el `ganadorId` persista el ID del equipo local.
6. **Paso B (Negativo / Defecto):** Enviar petición PUT con empate `1 - 1` y un `ganadorId = 99999` (equipo ajeno).
7. Verificar que el backend persiste el ID ajeno y documentar la respuesta como evidencia para Azure Boards.
