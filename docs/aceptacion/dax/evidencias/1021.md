* **Historia de Usuario:** Como administrador del sistema, quiero cancelar un torneo justificando la causa para suspenderlo formalmente.

## Guion de Pasos de Ejecución

1. Iniciar la Web API localmente en `http://localhost:5000` (o el puerto configurado).
2. Obtener un token JWT de administrador e insertarlo en la variable `@token` del archivo `api/1021_cancelar_torneo.http`.
3. Disponer de un `torneoId` registrado en la base de datos local.
4. **Paso A (Rechazo sin motivo):** Ejecutar la petición HTTP PUT `/api/Torneos/{{torneoId}}` enviando `estadoId = 4` y `motivoCancelacion = ""` (vacío).
5. Comprobar que la respuesta devuelva `400 Bad Request` indicando que el motivo es obligatorio.
6. **Paso B (Cancelación exitosa):** Ejecutar la petición HTTP PUT `/api/Torneos/{{torneoId}}` enviando `estadoId = 4` y `motivoCancelacion = "Reparación de iluminación de la sucursal"`.
7. Comprobar que la respuesta sea `200 OK` y el torneo pase a estado `4` (Cancelado).

---

## Resultados

### Resultado Esperado
* Sin motivo: Código HTTP `400 Bad Request` con mensaje *"Para cancelar el torneo es obligatorio ingresar una justa razón (motivo de cancelación)."*.
* Con motivo: Código HTTP `200 OK`, el torneo queda en `estadoId = 4` y se persiste la justificación.
