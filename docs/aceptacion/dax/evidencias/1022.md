## Guion de Pasos de Ejecución

1. Abrir la aplicación móvil **FutsalPro** en un dispositivo físico o emulador.
2. Navegar a la pestaña o menú **Torneos**.
3. Seleccionar un torneo que tenga partidos programados con resultados parciales o finales (ej. *Copa Relámpago*).
4. Verificar la visualización del árbol de llaves de **Cuartos de Final**:
   - Nombre de cada equipo.
   - Marcadores registrados (ej. `4 - 2`, `1 - 3`).
   - Identificación visual del equipo clasificado o ganador.
5. Realizar un gesto de arrastrar hacia abajo (*Pull-to-refresh*) o esperar el ciclo de sondeo para comprobar la actualización de marcadores.

## Resultados

### Resultado Esperado

* El equipo ganador se encuentra resaltado o marcado como clasificado.
