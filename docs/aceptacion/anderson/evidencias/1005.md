## Guion de Pasos de Ejecución

1. Iniciar la Web API localmente en `http://localhost:5000`.
2. Abrir el archivo `docs/aceptacion/anderson/api/1005_reserva_retroactiva.http`.
3. Establecer en el JSON de la solicitud una fecha/hora de inicio previa al momento actual (ej. 2 horas en el pasado o día anterior).
4. Ejecutar la petición HTTP `POST /api/Reservas`.
5. Constatar que el servidor evalúe la condición temporal y responda con código `400 Bad Request`.
6. Comprobar que el mensaje devuelto sea exactamente: `"La fecha y hora de inicio no puede ser anterior al momento actual."`.
7. Adjuntar la respuesta devuelta por la API en la sección de evidencia.
