## Guion de Pasos de Ejecución

1. Iniciar la Web API localmente en `http://localhost:5000`.
2. Abrir el archivo `docs/aceptacion/anderson/api/1007_modificar_reserva.http`.
3. Disponer del identificador `reservaId` de una reserva creada previamente.
4. Ajustar los campos en el cuerpo JSON de la solicitud PUT `/api/Reservas/{{reservaId}}` (ej. actualizar número de teléfono, nombre de contacto y precio total).
5. Ejecutar la petición HTTP PUT.
6. Validar que la API responda con código `200 OK` y el cuerpo JSON refleje exactamente los nuevos valores modificados.
7. Verificar que la propia reserva no colisione consigo misma durante la validación de solapamiento.
8. Registrar la respuesta en la sección de evidencia.
