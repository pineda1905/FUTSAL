## Guion de Pasos de Ejecución

1. Iniciar la Web API localmente en `http://localhost:5000` (o puerto configurado en `launchSettings.json`).
2. Abrir el archivo `docs/aceptacion/anderson/api/1003_crear_reserva_valida.http` en Antigravity IDE / VS Code con la extensión REST Client.
3. Asegurar que existe al menos una cancha activa (ej. `canchaId = 1`) y un usuario administrador (ej. `usuarioAdminId = 1`).
4. Configurar fechas de inicio y fin relativas válidas (ej. dentro de los próximos 3 días, respetando el límite máximo de 10 días).
5. Ejecutar la petición HTTP `POST /api/Reservas`.
6. Validar que la API responda con código `201 Created` y devuelva el objeto de la reserva creada con `nombreEstado: "Confirmada"` e `id > 0`.
7. Tomar captura de pantalla o copiar la respuesta JSON devuelta por la API.
